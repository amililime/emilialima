# emilialima

Personal site of Emilia Lima —  Fullstack Developer

Live: _coming soon_

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- `next/font` — Cormorant Garamond + DM Sans
- Deployed on Vercel

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
